# Project Name Suggestions

## Recommended name

### SkillForge AI

This name communicates technical skill development and assessment. It is professional, easy to pronounce internationally, and not limited to one programming language.

## Strong alternatives

### 1. TechHire Agent

Clear and direct. It immediately explains that the product is an AI agent for technical hiring.

### 2. InterviewOS

Positions the product as an operating system for technical interviews rather than a simple chatbot.

### 3. CodeSignal AI

Communicates measurable engineering evidence. It should be checked carefully for trademark conflicts before use because similar names exist in the market.

### 4. EvalForge

Strong for a product focused on evaluation, scoring, and evidence.

### 5. DevGauge

Short and technical. “Gauge” communicates measurement and benchmarking.

### 6. TalentLoop AI

Emphasizes the continuous loop between candidate answers, agent follow-up, evaluation, and human review.

### 7. SkillTrace

Highlights traceable evidence, code history, AI usage, and explainable scoring.

### 8. CodePilot Interview

Easy to understand, but less differentiated because “Pilot” is common in AI products.

### 9. HireProof AI

Emphasizes evidence-based hiring and verifiable candidate performance.

### 10. ForgeScreen

Suggests a technical screening process that tests how candidates build and debug real solutions.

## Naming recommendation

For an international product, use **SkillForge AI** or **InterviewOS**.

For a clear Turkish market message, use **TechHire Agent** or **Teknikİz**.

Before finalizing a name, check domain availability, GitHub organization availability, app-store conflicts, and trademark databases in Turkey and target markets.
